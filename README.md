# Irregular Verbs Trainer

An interactive, responsive **Blazor WebAssembly** application designed to help users master English irregular verbs through structured practice modes and real-time feedback.


## ✨ Features

*  **Complete Reference Table:** Interactive list displaying Infinitive ($V_1$), Past Simple ($V_2$), Past Participle ($V_3$), and Russian translations.
*  **Multiple Practice Modes:**
  *  **Write Mode:** Type the correct $V_2$ and $V_3$ forms manually.
  *  **Translation Mode:** Match Russian verbs to their corresponding English forms.
  *  **Multiple Choice:** Choose the correct pair of past forms from dynamic options.
*  **Real-Time Validation & Feedback:** Instant visual indicators for correct and incorrect answers with immediate display of missed forms.
*  **Session Results Summary:** Detailed breakdown of score accuracy alongside an aggregated list of mistakes made during the practice session.
*  **Clean Lavender UI:** Cozy, minimalist design crafted for an distraction-free learning environment.


## 🛠️ Built With

* **[Blazor WebAssembly](https://dotnet.microsoft.com/apps/aspnet/web-apps/blazor)** — Client-side C# Web UI framework.
* **.NET 10 SDK** — Application framework.
* **HTML5 / CSS3** — Custom modern styling with CSS variables.
* **GitHub Actions** — Automated CI/CD deployment pipeline.
